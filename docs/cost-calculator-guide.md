# 成本计算器使用指南

> 估算你的 AI API 调用成本，选择最省钱的模型和分组组合。

## 快速成本估算

### 基础概念

| 术语 | 含义 |
|------|------|
| 输入 Token | 你发送给模型的文本（包括系统提示、上下文） |
| 输出 Token | 模型返回的文本 |
| 倍率 | 分组的价格系数，越低越便宜 |
| 出入比 | 输出价格 / 输入价格（通常 3-8 倍） |

### 一次对话大概多少 Token

| 场景 | 输入 Token | 输出 Token |
|------|-----------|------------|
| 简单问答 | 50-200 | 100-500 |
| 代码生成 | 200-1000 | 500-2000 |
| 长文本分析 | 5000-50000 | 500-2000 |
| Claude Code 编程 | 5000-30000 | 2000-10000 |

## 按场景估算月成本

### 场景 1：日常 AI 对话（轻度使用）

- 日均 20 次对话
- 每次约 500 输入 + 500 输出 = 1000 token
- 月用量：约 60 万 token（30 万输入 + 30 万输出）

| 模型 | 分组 | 月成本 |
|------|------|--------|
| `gpt-5.6-luna` | 限时特价 (0.6x) | ~$0.36 |
| `gemini-2.5-flash` | Gemini-CLI 混合 (1.0x) | ~$0.90 |
| `claude-sonnet-5` | 默认 (1.0x) | ~$3.60 |

### 场景 2：AI 编程助手（中度使用）

- 日均 50 次代码请求
- 每次约 5000 输入 + 2000 输出 = 7000 token
- 月用量：约 1050 万 token（750 万输入 + 300 万输出）

| 模型 | 分组 | 月成本 |
|------|------|--------|
| `gpt-5.6-luna` | Codex 专属 (0.8x) | ~$9.12 |
| `gpt-5.6-sol` | Codex 专属 (0.8x) | ~$45.60 |
| `claude-sonnet-4-6` | 默认 (1.0x) | ~$67.50 |
| `claude-opus-4-8` | 默认 (1.0x) | ~$112.50 |

### 场景 3：Claude Code 重度编程

- 日均 100 次请求
- 每次约 15000 输入 + 5000 输出 = 20000 token
- 月用量：约 6000 万 token（4500 万输入 + 1500 万输出）

| 模型 | 分组 | 月成本 |
|------|------|--------|
| `claude-sonnet-4-6` | 默认 (1.0x) | ~$360 |
| `claude-sonnet-4-6` | CC 专属 (2.4x) | ~$864 |
| `claude-opus-4-8` | 默认 (1.0x) | ~$600 |

### 场景 4：长文本处理

- 日均 10 次文档分析
- 每次约 50000 输入 + 1000 输出
- 月用量：约 1530 万 token（1500 万输入 + 30 万输出）

## 省钱策略

### 1. 分组选择

| 策略 | 分组 | 倍率 | 适合 |
|------|------|------|------|
| 最省钱 | 限时特价 | 0.6x | 测试、非关键任务 |
| 性价比 | Codex 专属 | 0.8x | 日常编程 |
| 平衡 | 默认 | 1.0x | 生产环境 |
| 高稳定 | CC 专属 | 2.4x | Claude Code 编程 |

### 2. 模型混搭

不要只用一个模型。推荐策略：
- **简单任务**（翻译、摘要）：Gemini 2.5 Flash（$0.30/M 输入）
- **日常编程**：GPT-5.6 Luna（$0.80/M 输入）
- **复杂编程**：Claude Sonnet 4.6 或 GPT-5.6 Sol
- **超长文本**：Gemini 2.5 Pro（1M 上下文，$1.25/M 输入）

### 3. 缓存利用

Levolink 支持缓存价格（标准 10%）。对于重复发送相同上下文的场景（如 Claude Code），缓存可以大幅降低成本。

### 4. 设置 Token 限制

在应用层设置 max_tokens 限制，避免意外超支。

## 使用价格计算器脚本

仓库自带价格计算器脚本：

```bash
cd levolink-ai-api
python scripts/cost_calculator.py
```

输入你的预估用量，自动计算各模型/分组的月成本。
