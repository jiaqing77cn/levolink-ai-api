# 비용 계산기 사용 가이드

> AI API 호출 비용을 추정하고, 가장 저렴한 모델과 그룹 조합을 선택하세요.

## 빠른 비용 추정

### 기본 개념

| 용어 | 의미 |
|------|------|
| 입력 Token | 모델에 보내는 텍스트(시스템 프롬프트, 컨텍스트 포함) |
| 출력 Token | 모델이 반환하는 텍스트 |
| 배율 | 그룹의 가격 계수, 낮을수록 저렴 |
| 출입비 | 출력 가격 / 입력 가격(보통 3-8배) |

### 1회 대화당 대략적인 Token 수

| 시나리오 | 입력 Token | 출력 Token |
|------|-----------|------------|
| 간단한 Q&A | 50-200 | 100-500 |
| 코드 생성 | 200-1000 | 500-2000 |
| 긴 텍스트 분석 | 5000-50000 | 500-2000 |
| Claude Code 프로그래밍 | 5000-30000 | 2000-10000 |

## 시나리오별 월 비용 추정

### 시나리오 1: 일상 AI 대화 (경도 사용)

- 일평균 20회 대화
- 회당 약 500 입력 + 500 출력 = 1000 token
- 월 사용량: 약 60만 token(30만 입력 + 30만 출력)

## 비용 절감 전략

### 1. 그룹 선택

| 전략 | 그룹 | 배율 | 적합 |
|------|------|------|------|
| 최저가 | 한정 특가 | 0.6x | 테스트, 비핵심 작업 |
| 가성비 | Codex 전용 | 0.8x | 일상 프로그래밍 |
| 밸런스 | 기본 | 1.0x | 프로덕션 환경 |
| 고안정 | CC 전용 | 2.4x | Claude Code 프로그래밍 |

### 2. 모델 믹스

하나의 모델만 사용하지 마세요. 추천 전략:
- **간단한 작업**(번역, 요약): Gemini 2.5 Flash($0.30/M 입력)
- **일상 프로그래밍**: GPT-5.6 Luna($0.80/M 입력)
- **복잡한 프로그래밍**: Claude Sonnet 4.6 또는 GPT-5.6 Sol
- **초장 텍스트**: Gemini 2.5 Pro(1M 컨텍스트, $1.25/M 입력)

### 3. 캐시 활용

Levolink는 캐시 가격(표준 10%)을 지원합니다. 동일한 컨텍스트를 반복적으로 전송하는 시나리오(예: Claude Code)에서 캐시를 통해 비용을 크게 절감할 수 있습니다.

### 4. Token 제한 설정

애플리케이션 계층에서 max_tokens 제한을 설정하여 예상치 못한 초과 지출을 방지하세요.

## 가격 계산기 스크립트 사용

저장소에 가격 계산기 스크립트가 포함되어 있습니다:

```bash
cd levolink-ai-api
python scripts/cost_calculator.py
```

예상 사용량을 입력하면 각 모델/그룹의 월 비용이 자동으로 계산됩니다.
