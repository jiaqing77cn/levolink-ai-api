# コスト計算ツール使用ガイド

> AI API 呼び出しコストを見積もり、最もお得なモデルとグループの組み合わせを選ぶ。

## クイックコスト見積もり

### 基礎概念

| 用語 | 意味 |
|------|------|
| 入力 Token | モデルに送信するテキスト（システムプロンプト、コンテキスト含む） |
| 出力 Token | モデルから返却されるテキスト |
| 倍率 | グループの価格係数、低いほど安い |
| 出入比 | 出力価格 / 入力価格（通常 3-8 倍） |

| シーン | 入力 Token | 出力 Token |
|------|-----------|------------|
| 簡単な Q&A | 50-200 | 100-500 |
| コード生成 | 200-1000 | 500-2000 |
| 長文分析 | 5000-50000 | 500-2000 |
| Claude Code プログラミング | 5000-30000 | 2000-10000 |

## シーン別の月額コスト見積もり

### シーン 1：日常 AI チャット（軽度使用）

- 1日平均 20 回の対話
- 1回約 500 入力 + 500 出力 = 1000 token
- 月使用量：約 60万 token（30万入力 + 30万出力）

| モデル | グループ | 月額コスト |
|------|------|--------|
| `gpt-5.6-luna` | 限定特価 (0.6x) | ~$0.36 |
| `gemini-2.5-flash` | Gemini-CLI 混合 (1.0x) | ~$0.90 |
| `claude-sonnet-5` | デフォルト (1.0x) | ~$3.60 |

### シーン 2：AI プログラミングアシスタント（中度使用）

- 1日平均 50 回のコードリクエスト
- 1回約 5000 入力 + 2000 出力 = 7000 token
- 月使用量：約 1050万 token（750万入力 + 300万出力）

| モデル | グループ | 月額コスト |
|------|------|--------|
| `gpt-5.6-luna` | Codex 専用 (0.8x) | ~$9.12 |

### シーン 3：Claude Code ヘビープログラミング

## コスト削減戦略

### 1. グループ選択

| 戦略 | グループ | 倍率 | 適した用途 |
|------|------|------|------|
| 最安値 | 限定特価 | 0.6x | テスト、非クリティカルタスク |
| コスパ | Codex 専用 | 0.8x | 日常プログラミング |
| バランス | デフォルト | 1.0x | 本番環境 |
| 高安定 | CC 専用 | 2.4x | Claude Code プログラミング |

### 2. モデルの組み合わせ

1つのモデルだけを使わないでください。推奨戦略：
- **簡単なタスク**（翻訳、要約）：Gemini 2.5 Flash（$0.30/M 入力）
- **日常プログラミング**：GPT-5.6 Luna（$0.80/M 入力）
- **複雑なプログラミング**：Claude Sonnet 4.6 または GPT-5.6 Sol
- **超長文**：Gemini 2.5 Pro（1M コンテキスト、$1.25/M 入力）

### 3. キャッシュ活用

Levolink はキャッシュ価格（標準 10%）をサポートしています。同じコンテキストを繰り返し送信するシーン（Claude Code など）では、キャッシュによりコストを大幅に削減できます。

### 4. Token 制限の設定

アプリケーション層で max_tokens 制限を設定し、予期せぬコスト超過を防ぐ。

## 価格計算スクリプトの使用

リポジトリに価格計算スクリプトが付属しています：

```bash
cd levolink-ai-api
python scripts/cost_calculator.py
```

見積もり使用量を入力すると、各モデル/グループの月額コストを自動計算します。
